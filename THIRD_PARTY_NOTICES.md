| SDK file | How it is used |
|---|---|
| `icap.h` | API header. Its inline wrapper functions are compiled into the app. |
| `tools/icap_start.S` | App entry stub, assembled and linked into the app. |

## English word list (SCOWL)

`src/dict_en.c` and `radio/SKIMDICT.BIN` (copied to `app/`) hold about 4,000 of the most common English words, taken from **SCOWL** (Spell Checker Oriented Word Lists) size 10, version 2020.12.07, <http://wordlist.aspell.net/>. They are generated by `tools/mkdict.py`; the word-spacing fix uses them to join and split words. The list is not MIT-licensed; it is under SCOWL's own permissive terms:

## Compiler runtime

`SKIM.APP` is linked with `libgcc` from the GNU Arm toolchain (`arm-none-eabi-gcc`). `libgcc` is covered by the GCC Runtime Library Exception, which allows linking it into programs under any license.

## No other third-party code

Apart from the English word list above, the decoder core, the callsign logic, the word-spacing fix and its CW vocabulary, the desktop tools and the desktop simulator contain no third-party code. The Morse table, the Goertzel and filter code, the Viterbi detector and the WAV reader were all written for this project.
